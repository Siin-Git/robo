## 휴장일 표시

랭킹, 누적 성과, 기여도, 고점 대비 낙폭의 표시 날짜에 동일한 규칙을 적용했다. 9월 24·25일은 원래 재생 자료에 명시된 정상 휴장으로 앞뒤 관측이 이어진다. 가격·NAV·기여도·수익률을 새로 생성하거나 보간하지 않는다. 서버 응답의 null, 날짜, 품질 조건과 평가 11개도 그대로 남는다.

달력 표시와 실제 관측이 충돌하면 실제 관측을 보존한다. 랭킹에서는 어느 참가자나 CORE에 실제 값이 있으면 그 날짜를 제거하지 않는다. 확인되지 않은 자료 누락·참가자별 평가 공백은 null과 선의 끊김으로 표시한다. `connectNulls=true`로 모든 누락을 연결하지 않는다. 위험 순위와 연율 변동성의 기존 품질 제한도 변경하지 않는다.
