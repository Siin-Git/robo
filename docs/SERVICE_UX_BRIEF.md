# 서비스 화면 정리 — 실행 프롬프트

기존 Robo Advisor 저장소와 배포 사이트를 대상으로 작업한다. 새 프로젝트나 별도 목업을 만들지 않는다.

목표는 사용자가 현재 자산 상태를 확인하고, 자신이 고른 구성의 위험을 이해한 뒤 유지·재검토 이유를 남길 수 있게 하는 것이다. 개발 과정과 검증 체계를 설명하는 화면보다 실제 사용 흐름을 우선한다.

## 적용할 원칙

1. 대시보드는 자산, 수익률, 기준 구성과의 차이, 보유자산에 집중한다. 다음 행동은 ‘내 선택 점검’ 하나를 강조한다.
2. ‘과거 재현’, ‘모의운용’ 같은 구현 구분을 상단 배지·카드·차트 설명에 반복하지 않는다. 출처, 구간별 기록, 계산 방식은 ‘계산 기준과 데이터 확인’에서 조회할 수 있게 보존한다. 실제 계좌 거래가 이루어지지 않는다는 안내는 하단 한 문장으로 남긴다.
3. 같은 수치나 메뉴를 반복하는 카드는 제거한다. 처음 보는 사용자가 설명을 읽지 않아도 버튼을 누른 뒤 무엇을 볼지 알 수 있게 이름을 붙인다.
4. 내 선택 점검은 저장한 구성의 위험 비교, 과거 하락장 리허설, 유지·조정 이유 기록으로 이어진다. 최초 판단은 덮어쓰지 않는다.
5. 기존 다크 색상, 여백, 카드, 글꼴, 포커스 표시를 재사용한다. 새 배너·슬로건·애니메이션으로 빈 공간을 채우지 않는다. 모바일에서도 주요 행동을 숨기지 않는다.
6. 수치, 데이터 출처, 누락 상태, 오류 안내는 실제 API에 근거한다. 출처 설명을 접는 것을 실제 운용 성과로 바꾸는 것으로 해석하지 않는다. 합성 테스트 자료 표시는 유지한다.

## 이번 적용 범위

- 대시보드의 반복 배지·출처 문장·기록 카드 제거, 단일 점검 행동 강조.
- 공통 사이드바의 설명용 부제 제거.
- 포트폴리오의 리허설 진입부를 짧은 행동 카드로 정리하고 위험 비교 안내를 간결하게 변경.
- 서버 계산, 원장, 자동 실행 설정은 그대로 유지.

## 완료 기준

- 대시보드에서 자산과 수익률을 확인한 뒤 한 번의 클릭으로 내 구성 점검에 도달한다.
- 계산 상세를 열면 과거 재현과 시작 이후 NAV의 출처·날짜·수치를 확인할 수 있다.
- 오류·미확보·테스트 자료 상태를 숨기지 않는다.
- 기존 회귀 검사와 production 빌드가 통과한다. 배포 화면에서 주요 동선, 문구, 잘림을 확인한다.

이 작업은 화면의 사용성과 일관성을 개선한다. 자동화 안정성, 투자 성과, 반복 사용 의사가 검증됐다는 의미는 아니다.
