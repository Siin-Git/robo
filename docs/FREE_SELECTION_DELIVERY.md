# 자유 선택과 재구성 연결

사용자가 최대 두 Theme와 선택 이유를 저장하면 현재 구성의 가격 기반 과거 비교를 대시보드, 순위, 상세에서 함께 보여준다. 재구성은 본인만 수행하고 다른 참가자의 계정 및 과거 장부를 변경하지 않는다.

## 결정

- 기존 가상 NAV는 삭제하거나 실제 운용 이력으로 바꾸지 않는다. 비교 화면은 모든 참가자를 동일한 시장 가격·기간·계산법으로 다시 평가한다. 신규 사용자만 실제 가격 결과를 기존 가상 순위에 섞지 않는다.
- 기존 가격 저장소의 시장 데이터만 배포 가능한 압축 CSV로 추출한다. 계정, 비밀번호, 세션 및 개인 포트폴리오는 포함하지 않는다. 출처·기간·해시를 manifest에 기록한다.
- 현재 목표 비중을 공통 시작일에 투자한 매수 후 보유 평가를 사용한다. 실제 운용 및 투자 시점에 알려진 전략의 검증 결과가 아니라는 점, 비용·세금 미포함을 화면에 표시한다.
- 재구성의 최신 확정 비중은 기존 설계 DB에서 조회한다. 초안은 순위에 반영하지 않는다. 최초 실험 구성과 기존 NAV는 보존한다.
- 시연 프로필의 `CAPSTONE_MARKET_COMPARISON=1`로 전환한다. 일반 운영 프로필의 계산·DB는 유지한다.
- 재배포 전 현재 Render SQLite 계정 보존을 확인해야 한다. 초기화·seed 재실행으로 기존 계정을 대체하지 않는다.

## 완료 기준

- 지원 Theme 9개에 대한 0/1/2개 모든 조합에서 유한한 위험값 및 가격 비교 결과.
- 신규 AI+바이오 참가자도 13명 순위에 포함.
- 본인 재구성 후 새로고침·재로그인·랭킹·상세 수치 일치. 다른 사람 구성과 원래 가상 NAV 불변.
- 배포에는 가격 파일 포함. API 및 브라우저 회귀 검증.

실제 일별 운용 스케줄러, 매매 주문, 비용 포함 전략 백테스트, 유료 인프라 전환은 별도 범위다.

## 검증 기록

- Backend 전체: 148 passed, 3 skipped. 기존 라이브러리 경고만 존재.
- Frontend: 47 passed. Production build 및 타입 검사 통과.
- 46개 조합의 가격 대사, 위험 한도, 결측·잘못된 비중 처리 검증.
- AI+바이오 신규 참가자도 13명 순위에 포함. 본인 재구성 후 Theme·이유·성과 갱신, 초안과 저장 구성 구분, 재로그인 및 CSRF 확인.
- 기존 12명의 계정·저장된 비중·가상 NAV 불변 확인. 과거 가격 비교의 표시 수치는 동일 시장 데이터로 다시 산출되므로 기존 가상 시나리오 수치와 다르다.
- 기존 DB를 임시 디렉터리에 복사한 별도 서버에서 가입·생성·13명 순위를 확인했다. 실제 로컬 DB와 Production 슬롯은 소비하지 않았다.
- 실제 브라우저 대시보드에서 AI+바이오의 누적수익률·변동성·재구성 링크를 확인했다. 이후 화면 검증은 사용자에게 맡겼다.

## 배포 설정과 데이터 보존

Backend에 `CAPSTONE_MARKET_COMPARISON=1`을 설정하고 `data/market/`를 포함한다. Frontend는 API의 `market_comparison`과 `data_source`에 따라 표시하며 새로운 공개 환경변수는 필요 없다.

2026-09-20 현재 무료 Render는 Shell/SSH 접근이 없어 실행 중인 SQLite의 비밀번호 해시를 백업할 수 없다. 재배포 시 기존 demo 계정이 사라질 수 있으므로 데이터 소실 승인 또는 보존 수단을 확보하기 전 재배포하지 않는다. 사용자 승인 없이 DB 초기화·seed 재실행을 하지 않는다.

AI가 구현·테스트를 작성했으며 위 통과 기록은 실제 실행 결과에 근거한다. 가격 파일에는 시장 데이터만 있고 개인 계정·초대 코드·세션은 없다.
